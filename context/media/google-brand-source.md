# Google mark provenance

The compact review header uses Google's unmodified full-color G PNG, downloaded from the Google Partner Marketing Hub's **Logos / How to show Google's brand** page:

- Guidance and download page: https://partnermarketinghub.withgoogle.com/brands/google/branding-guidelines/how-to-show-googles-brand/
- Customer review context: https://partnermarketinghub.withgoogle.com/brands/google/use-cases/customer-reviews/
- Original download object: `https://storage.googleapis.com/pe-portal-consumer-prod-wagtail-static/original_images/GoogleG_FullColor_RGB.png` (the page provides a temporary signed download URL; its expiring query is not stored here).
- Repository asset: `public/images/brands/google-g.png`, 2820 × 2820, 137,714 bytes.

The original has substantial transparent canvas surrounding the 920 × 940 mark. CSS frames that transparent canvas within a 48px slot, rendering the original image at 108px; the colored mark appears about 36px tall. Its colors and proportions are unchanged. Next Image supplies a small optimized rendition, rather than loading the full source into the page.

The mark identifies the source beside “Reviews on Google.” The separate numeric rating treatment is sourced from the existing approved rating record. It is not a certification, Google endorsement or partner badge. No total count is advertised. The existing internal rating source URL and checked-at date remain in `lib/google-reviews.js`; neither a visible date nor a profile link is reintroduced.
